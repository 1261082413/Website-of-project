# Haoyu Du Project Website

A Django portfolio website showing project summaries, GitHub links, playable demos, and design-process breakdowns.

## What changed in this version

- Added design-thinking sections to the main game and modelling project pages.
- Added visual design-deck galleries generated from the uploaded PDF presentations.
- Added compact PDF links for each original design deck.
- Updated project names and summaries for:
  - Missile Command
  - Blade and Bow
  - Shattered Shadows
  - Moon Guitar
- Added responsive styling for design pillars, takeaways, and slide galleries.

## Run locally

```bash
pip install -r requirements.txt
python manage.py runserver
```

Then open the local Django URL in your browser.
